## How to Use the New Features

### Navigation

**Desktop:**
- Click any new category in the top navigation bar
- Categories: Prophets, Prophecy, Epistles, Creation, Stories

**Mobile:**
- Tap the hamburger menu (three lines)
- Scroll to find the new categories
- All categories now appear in the mobile drawer

### Exploring Passages

1. **Select a Category** - Click any of the new categories
2. **Browse Passages** - See all available passages with themes and musical keys
3. **Search** - Use the search bar to find specific passages
4. **Select a Passage** - Click any passage to view full details
5. **Play Music** - The Music Machine automatically loads with the passage
6. **Study & Memorize** - Use TTS, tempo controls, and all musical features

### Musical Integration

Every passage includes:
- **Musical Key** - Appropriate key signature for the theme
- **Tempo** - BPM for rhythm
- **Time Signature** - Musical meter
- **Theme** - Theological focus
- **Full Music Machine** - All chord progressions, voicing patterns, arpeggio sequences, strum patterns, and audio effects work with every passage

## Technical Details

### File Structure
```
src/data/
├── gospelPassages.ts      (EXPANDED - 80 passages)
├── prophetsPassages.ts    (NEW - 10 passages)
├── prophecyPassages.ts    (NEW - 12 passages)
├── epistlesPassages.ts    (NEW - 14 passages)
├── creationPassages.ts    (NEW - 10 passages)
└── storiesPassages.ts     (NEW - 15 passages)

src/components/
├── ProphetsPage.tsx       (NEW)
├── ProphecyPage.tsx       (NEW)
├── EpistlesPage.tsx       (NEW)
├── CreationPage.tsx       (NEW)
└── StoriesPage.tsx        (NEW)
```

### Data Format
All passages follow a consistent structure:
```typescript
{
  id: string;
  reference: string;       // e.g., "Romans 8:28-39"
  title: string;          // e.g., "More Than Conquerors"
  category: string;       // e.g., "Epistles"
  theme: string;          // e.g., "Victory in Christ"
  key: string;            // e.g., "D Major"
  tempo: number;          // e.g., 92 (BPM)
  timeSignature: string;  // e.g., "4/4"
  text: string;           // Full KJV scripture text
  background: string;     // Context and explanation
}
```
