# 🎸 HOW TO USE STRUM & BROKEN CHORD PATTERNS

## 🎯 QUICK START GUIDE

### Using Strum Patterns (New!)

**Step 1:** Find the Voicing Technique buttons
- Located in the main control panel
- You'll see 5 buttons: Block, Arpeggiated, **Strum**, Broken, Partial

**Step 2:** Click the **"Strum"** button
- Button will highlight when selected
- This activates strum mode

**Step 3:** Open Advanced Options
- Click the **"Advanced Options"** button
- Located below the tempo controls
- A panel will slide open

**Step 4:** Choose a Strum Pattern
- Patterns are grouped by style:
  - **Basic Strums** - Downstroke, Upstroke, Alternating
  - **Folk/Acoustic** - Travis Picking, Fingerstyle
  - **Latin/World** - Bossa Nova, Reggae, Flamenco
  - **Jazz/Blues** - Shuffle, Swing, Gypsy Jazz
  - **Rock/Funk** - Muted, Metal, Power Chords
  - **Special** - Ska, Waltz, Country, Tremolo
- Click any pattern card to select it
- Selected pattern highlights in orange

**Step 5:** Click Play
- Your chord progression will play with the strum pattern
- Listen to the guitar-style strumming!

---

### Using Broken Chord Patterns (Enhanced!)

**Step 1:** Click the **"Broken"** button
- Located in the Voicing Technique section

**Step 2:** Open Advanced Options
- Click the **"Advanced Options"** button

**Step 3:** Choose a Broken Chord Pattern
- Patterns are grouped by starting note:
  - **From Root** - Patterns starting with the root note
  - **From Third** - Patterns starting with the 3rd
  - **From Fifth** - Patterns starting with the 5th
  - **From Seventh** - Patterns starting with the 7th
  - **Extensions** - Patterns using 9th, 11th, 13th
- Click any pattern card to select it
- Selected pattern highlights in yellow

**Step 4:** Click Play
- Your progression plays with broken chord patterns
- Single note followed by two-note combinations

## 🎵 PATTERN EXAMPLES

### Strum Patterns

**Basic Down-Quarter:**
- Simple downstroke on each quarter note
- Great for beginners
- Even, steady rhythm

**Folk Alternating:**
- Alternating bass notes with strums
- Classic folk guitar sound
- Medium complexity

**Bossa Nova:**
- Syncopated Latin rhythm
- Smooth, jazzy feel
- Advanced pattern

**Reggae Upstroke:**
- Upstrokes on off-beats
- Classic reggae sound
- Rhythmic and bouncy

---

### Broken Chord Patterns

**Root + Third-Fifth:**
- Root note alone, then 3rd + 5th together
- Classic arpeggio feel
- Works with any chord

**Third + Root-Fifth:**
- Starts with 3rd for color
- Root + 5th provide foundation
- Jazzy flavor

**Fifth + Third-Seventh:**
- Starts from the top
- Great for sus chords
- Contemporary sound

**Root + Ninth-Eleventh:**
- Extended harmony
- Modern jazz voicing
- Requires 9th and 11th in chord

## 💡 TIPS & TRICKS

### For Strum Patterns:

1. **Match Style to Genre:**
   - Folk songs → Folk/Acoustic patterns
   - Rock songs → Rock/Funk patterns
   - Latin songs → Latin/World patterns

2. **Experiment with Direction:**
   - Downstroke = Power and drive
   - Upstroke = Light and bouncy
   - Alternating = Smooth and flowing
   - Mixed = Unpredictable and organic

3. **Try Different Articulations:**
   - Legato = Smooth, connected
   - Staccato = Short, choppy
   - Muted = Damped, percussive

### For Broken Chord Patterns:

1. **Start with Simple Patterns:**
   - Begin with Root-based patterns
   - Move to Third and Fifth patterns
   - Try Extensions for jazz flavor

2. **Consider the Chord Type:**
   - Triads (3 notes) → Use Root/Third/Fifth patterns
   - 7th chords (4 notes) → Use Seventh patterns
   - Extended chords → Use Extension patterns

3. **Listen for the Groove:**
   - Accent patterns create rhythm
   - Some patterns are syncopated
   - Some are straight and simple

## 🐛 TROUBLESHOOTING

**Problem:** Pattern doesn't sound right
- **Solution:** Make sure you've selected the right pattern in Advanced Options
- Check console logs to verify pattern selection

**Problem:** Can't hear the strum effect
- **Solution:** Ensure "Strum" button is highlighted (active)
- Try a different strum pattern
- Increase tempo to hear the difference more clearly

**Problem:** Broken chord pattern sounds incomplete
- **Solution:** Pattern may need extended chord tones (9th, 11th, 13th)
- Try selecting chord type with more notes (7th, 9th, etc.)
- Use a different pattern from the "From Root" category

**Problem:** Pattern sounds too fast/slow
- **Solution:** Adjust the tempo using the BPM slider
- Try patterns designed for your tempo range
- Fast patterns work best at 90-140 BPM
