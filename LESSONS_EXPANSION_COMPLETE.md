## Implementation Notes

### Technical Requirements:
- Each lesson must have interactive melody/harmony builder
- Visual feedback for note/chord placement
- Audio playback with Tone.js
- Scripture integration
- Progress tracking
- Score calculation based on accuracy

### Difficulty Progression:
- **Partial/Beginner:** 2-5 elements
- **Composite/Intermediate:** 6-8 elements
- **Full/Advanced:** 8+ elements

### All lessons follow the same component structure:
```typescript
interface Lesson {
  id: string;
  title: string;
  description: string;
  type: string; // specific to category
  elements: any[]; // notes, chords, rhythms, etc.
  scripture: string;
}
```
