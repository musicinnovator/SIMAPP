# Quick Reference - Enhanced Music Machine Features

## 🎹 Chord Quality Modes

| Mode | What It Does | Use For |
|------|--------------|---------|
| **Key-Aware** ⭐ | Respects key signature (diatonic) | Traditional music, hymns, theory-correct songs |
| **All Major** | Makes every chord major | Bright, happy songs |
| **All Minor** | Makes every chord minor | Dark, somber songs |
| **All Dominant 7th** | Makes every chord dom7 | Blues, jazz, gospel |
| **Mixed** | Random major/minor | Experimentation |

⭐ = Default

## ⏱️ Time Signatures

| Signature | Feel | Example Songs | Use For |
|-----------|------|---------------|---------|
| **4/4** ⭐ | Common time | Most hymns | General purpose |
| **3/4** | Waltz | "Holy, Holy, Holy" | Waltzes, flowing songs |
| **6/8** | Compound | "Silent Night" | Celtic, pastoral |
| **2/4** | March | Children's songs | Quick, energetic |
| **5/4** | Unusual | "Take Five" | Modern, complex |
| **7/8** | Complex | Progressive music | Experimental |

⭐ = Default

## 🎵 Arpeggio Patterns (when Voicing = Arpeggiated)

| Category | Patterns | Description |
|----------|----------|-------------|
| **Four-Note** | 1-3-5-3, 1-5-3-5, etc. | Standard repeating patterns |
| **Three-Note** | 1-3-5, 1-5-3, etc. | Faster, simpler |
| **Octave** | 1-3-5-8, 8-5-3-1 | Dramatic range |

**Pattern Key**: 1=root, 3=third, 5=fifth, 8=octave

## 💾 Save/Load Operations

| Action | Steps | Notes |
|--------|-------|-------|
| **Save** | Name it → Click 💾 | Must be signed in |
| **Load** | Open manager → Click Load | All settings restore |
| **Delete** | Open manager → Click 🗑️ | Confirms first |
| **Combine** | Click Combine → Select 2nd | Max 24 chords |

## 🔑 Keyboard Shortcuts

- **Space**: Play/Stop
- **F12**: Open console (for debugging)

## ⚠️ Important Notes

1. **Voice-Leading**: When ON, it disables manual Inversion
2. **Quality Mode**: Works with any Chord Type
3. **Time Signature**: Changes chord duration, not BPM
4. **Arpeggio Patterns**: Only work when Voicing = "Arpeggiated"
5. **Save/Load**: Requires authentication

## 🐛 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Quality mode not working | Check you're not in "Key-Aware" + verify Chord Type |
| Can't hear time signature change | Listen to chord duration (how long each plays) |
| Can't save | Must be signed in + enter a name |
| Patterns not playing | Set Voicing to "Arpeggiated" |
| Inversion disabled | Turn off Voice-Leading |

## 🎯 Quick Start

1. Choose a key
2. Select time signature (try 3/4 for waltz feel)
3. Pick chord type (try 7th for rich sound)
4. Select quality mode (try "All Dominant 7th" for blues)
5. Choose voicing (try "Arpeggiated")
6. Pick pattern (try "1-3-5-8")
7. Press Play!
8. Save your creation!

**Experiment and discover! 🎉**
