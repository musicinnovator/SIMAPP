# Real-Time Parameter Changes - Quick Reference Card

## 🎯 What Is This?

Change music parameters (voicing, tempo, volume, etc.) **while playing** and have them apply smoothly at the perfect moment!

---

## ⚡ Quick Start (3 Steps)

1. **Start playing music** in MusicMachine
2. **Scroll down** to "Real-Time Parameter Changes" panel
3. **Toggle ON** and select "Next Loop" timing

Done! Now make changes during playback and they'll queue automatically.

---

## 🎛️ What Can Be Changed Real-Time?

### HIGH PRIORITY ✅
- **Voicing Patterns**: Block → Arp → Strum → Broken → Partial
- **Pattern Variations**: Different strum/arp patterns
- **Tempo/BPM**: Speed up or slow down
- **Volume**: Music and voice levels

### MEDIUM PRIORITY ✅
- **Octave Range**: Shift voicing up/down
- **Voicing Styles**: Drop 2, Close, Open
- **Instrument**: Piano, Organ, Strings, etc.

---

## ⏱️ Timing Modes (Option C)

| Mode | When Applied | Best For |
|------|--------------|----------|
| ⚡ **Immediately** | Right now | Quick experiments |
| ⏭️ **Next Chord** | At next chord | Smooth transitions |
| 🔄 **Next Loop** ⭐ | When progression loops | Most musical |
| ⏹️ **Manual** | On stop/play | Full control |

## 🎮 Common Workflows

### **Building Intensity**
1. Start with Block chords (simple)
2. After 1 loop → Switch to Broken (adds movement)
3. After 1 loop → Switch to Strum (full texture)
4. After 1 loop → Back to Block (resolution)

### **Tempo Journey**
1. Start at 80 BPM (relaxed)
2. Increase to 100 BPM (more energy)
3. Increase to 120 BPM (driving)
4. Drop to 60 BPM (dramatic ending)

### **Pattern Exploration**
- Click different patterns while playing
- Watch them queue up
- Hear each one as it applies
- Cancel any you don't like

---

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Changes not applying | Check system is ON, music is PLAYING |
| Changes are jarring | Switch from "Immediately" to "Next Loop" |
| Don't see settings | Scroll down in MusicMachine section |
| Badge blocking view | Click to minimize |

---

## 💡 Pro Tips

1. **Start with "Next Loop"** - Most musical results
2. **Cancel if unsure** - Click X before it applies
3. **Experiment freely** - No risk while queued
4. **Turn OFF if not needed** - Works exactly like before
