## Technical Notes

### File Structure
- Gospel passages remain in single file: `src/data/gospelPassages.ts`
- New categories have separate files for modularity:
  - `src/data/prophetsPassages.ts`
  - `src/data/prophecyPassages.ts`
  - `src/data/epistlesPassages.ts`
  - `src/data/creationPassages.ts`
  - `src/data/storiesPassages.ts` (pending)

### Data Format
All passages follow this structure:
```typescript
{
  id: string;              // Unique identifier
  reference: string;       // Bible reference
  title: string;           // Passage title
  category: string;        // Category name
  theme: string;           // Thematic description
  key: string;             // Musical key
  tempo: number;           // BPM (40-240)
  timeSignature: string;   // e.g., '4/4', '3/4'
  text: string;            // Full scripture text (KJV)
  background: string;      // Contextual information
}
```
